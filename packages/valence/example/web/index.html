    Login and secrets
    
      
    
        The token goes to the host, not into the page's storage: the host attaches it to every sync of
        shelf, including the ones it runs while this page is not on screen.
      
    
      
      
      
      
      
      
    reading auth.hasToken…
    
      
    
        Naming a different account clears every writable bucket and the outbox, so the next
        person on this phone does not read the last one's notes. It refuses while a note is still
        queued; tick the box to drop those notes unsent.
      
    
      
    
    

    
    
      
    Lifecycle, connectivity and updates
    
      
    
        Four lifecycle states rather than Flutter's five, connectivity as the OS reports
        interfaces (never reachability), and the reason the last update check ended as it did.
